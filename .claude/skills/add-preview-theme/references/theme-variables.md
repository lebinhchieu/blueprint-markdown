# Theme Variable Contract

Every palette block in `media/em-theme.css` must define the following custom properties.
Missing any one causes silent fallback to the light `:root` value — a subtle but visible bug.

---

## Token groups and what they control

### Semantic colors (7 roles × 3 vars each = 21 vars)

Each semantic role has three variables:
- `--c-<role>` — the accent color (border, icon, bullet)
- `--c-<role>-bg` — the background for tinted surfaces (callout, chip fill)
- `--c-<role>-text` — text rendered inside that tinted surface

| Token | Controls |
|-------|----------|
| `--c-primary` / `--c-primary-bg` / `--c-primary-text` | Primary actions, links, card borders, step numbers |
| `--c-success` / `--c-success-bg` / `--c-success-text` | Success callout, ✓ chips |
| `--c-warning` / `--c-warning-bg` / `--c-warning-text` | Warning callout, ⚠ chips |
| `--c-danger` / `--c-danger-bg` / `--c-danger-text` | Danger callout, error chips |
| `--c-info` / `--c-info-bg` / `--c-info-text` | Info callout, note chips |
| `--c-gray` / `--c-gray-bg` / `--c-gray-text` | Neutral callout, gray chips, muted icons |
| `--c-low` / `--c-low-bg` / `--c-low-text` | Low-priority / "low" severity chips |

### Background layers (4 vars)

| Token | Controls |
|-------|----------|
| `--bg-base` | Page/body background |
| `--bg-surface` | Cards, panels, slightly elevated surfaces |
| `--bg-raised` | Modals, tooltips, top-level raised surfaces |
| `--bg-overlay` | Hover states, selection tints, overlays |

### Text (4 vars)

| Token | Controls |
|-------|----------|
| `--text-base` | Primary readable text |
| `--text-muted` | Secondary text, metadata, captions |
| `--text-faint` | Placeholder text, decorative dividers |
| `--text-on-solid` | Text on solid-color filled backgrounds (chips, buttons) |

### Borders (2 vars)

| Token | Controls |
|-------|----------|
| `--border-color` | Default border |
| `--border-color-muted` | Subtle / de-emphasized border |

### Shadows (3 vars)

| Token | Controls |
|-------|----------|
| `--shadow-sm` | Subtle elevation (chips, inline components) |
| `--shadow-md` | Card / panel elevation |
| `--shadow-lg` | Overlay / modal elevation |

### Code blocks (3 vars)

| Token | Controls |
|-------|----------|
| `--code-bg` | Background of `pre` / fenced code blocks |
| `--code-border` | Border of fenced code blocks |
| `--code-hl-bg` | Line highlight background (line-number annotation) |

> `--code-bg` is also consumed by `media/hljs.css` (generated by `esbuild.mjs`) as the
> code block background color, overriding the hardcoded value from atom-one-dark.

### Tooltip (2 vars)

| Token | Controls |
|-------|----------|
| `--tooltip-bg` | Tooltip background |
| `--tooltip-text` | Tooltip text color |

## Blank copy-paste template

```css
body[data-em-theme="<key>"] {
  --c-primary:      ;   --c-primary-bg: ;   --c-primary-text: ;

  --c-success:      ;   --c-success-bg: ;   --c-success-text: ;

  --c-warning:      ;   --c-warning-bg: ;   --c-warning-text: ;

  --c-danger:       ;   --c-danger-bg:  ;   --c-danger-text:  ;

  --c-info:         ;   --c-info-bg:    ;   --c-info-text:    ;

  --c-gray:         ;   --c-gray-bg:    ;   --c-gray-text:    ;

  --c-low:          ;   --c-low-bg:     ;   --c-low-text:     ;

  --bg-base:    ;
  --bg-surface: ;
  --bg-raised:  ;
  --bg-overlay: ;

  --text-base:     ;
  --text-muted:    ;
  --text-faint:    ;
  --text-on-solid: ;

  --border-color:       ;
  --border-color-muted: ;

  --shadow-sm: ;
  --shadow-md: ;
  --shadow-lg: ;

  --code-bg:     ;
  --code-border: ;
  --code-hl-bg:  ;

  --tooltip-bg:   ;
  --tooltip-text: ;
}
```
